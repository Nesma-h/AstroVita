---
name: Helmet icon transparency
description: Preserve the intended black visor when processing AstroVita's astronaut brand icon.
---

Keep the helmet visor opaque black; make only the surrounding background transparent.

**Why:** The uploaded pixel-art icon uses the same black for its background and visor. Automatic removal and edge-connected color removal both erase the visor because the regions connect through gaps.

**How to apply:** Review processed versions against a contrasting background and restore the visor's opacity without restoring a rectangular background.
