---
name: Official resource verification
description: How to distinguish changing challenge resources from actual sensor datasets
---

Re-fetch the official NASA challenge Resources tab before concluding that resources are unavailable, especially when the user says the page contains information.

**Why:** The resource page changed from a placeholder to published HRP and partner links during the same day's work. The earlier availability conclusion was already stale.

**How to apply:** Follow and inspect the live official links. Distinguish qualitative risk/research documentation from per-astronaut observations, sensor schemas, thresholds, and live feeds; the former does not imply that the latter exists.
